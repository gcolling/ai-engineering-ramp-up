# AI Engineering Ramp-Up

A 16-week hands-on training program focused on practical AI engineering,
automation and systems integration.

## Target roles

- AI Engineer
- Applied AI Engineer
- AI Developer
- AI Integration Engineer
- AI Automation Engineer
- Agentic AI Engineer

## Duration and workload

16 weeks.

Baseline workload:

- approximately 3 focused hours per study day
- approximately 15 focused hours per week
- optional catch-up/project time when useful

The program prioritizes consistency over long study sessions.

## Learning method

Each topic progresses through:

1. Theory — What, Why and How
2. Small experiments
3. Guided implementation
4. Independent exercise
5. Adversarial / failure testing
6. Production considerations
7. Review and assessment

The emphasis is on understanding and building systems rather than
collecting certificates.

## Main areas

- LLM application engineering
- Structured outputs
- Tool / function calling
- RAG
- Embeddings and vector search
- AI agents
- LangGraph
- MCP
- FastAPI
- AI evaluation
- Observability
- AI security
- Docker
- Integration architecture
- Workflow automation

## Work priorities

Each task is classified as:

- MUST — required
- SHOULD — valuable if time permits
- STRETCH — optional depth

Stretch work must never block progress through the core curriculum.
